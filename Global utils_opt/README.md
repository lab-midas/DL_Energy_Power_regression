# 🌐 Global Utils

This module provides general utility functions and configurations used throughout <br>
the entire pipeline, promoting code reuse and maintainability.

**Key Features:**
- 🎨 Color scheme setup and activation of predefined stylesheets
- 🗂️ Body region grouping configuration
- 📥 Data loading utilities
- 🧹 Data filtering functions
- 🏷️ Scanner and body region mapping
- 🔤 Column sorting by suffix and alphabetical order
- 💾 Figure saving in multiple formats
- 📊 Summary CSV creation: includes column data types, unique values, and more
